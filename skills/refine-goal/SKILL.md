---
name: refine-goal
description: Turn a vague want into a clear, confirmed goal statement before any solution work. Use when the user's goal is fuzzy, when a request may be a solution in disguise, or when the user says "help me figure out what I want", "clarify the goal", "what am I actually trying to do".
disable-model-invocation: true
---

Interview the user until the goal is clear enough that two people would build toward the same outcome.

Hold a **goal statement** with these fields:

- **Outcome**: what is true when the goal is met.
- **Why**: the need behind the goal. Ask "why" until the answer stops changing.
- **Success criteria**: observable signs that the goal is met.
- **Constraints**: hard limits (time, budget, tech, people).
- **Non-goals**: what is explicitly out of scope.

Mark each field **stated**, **inferred**, or **unknown**. Show the statement at the start and after every round.

Stress-test the goal, not only the fields:

- Is it a goal, or a solution in disguise? If the user asks for X, find out what X is for.
- Is it one goal or several? Split compound goals and ask which one comes first.
- Could the success criteria be met while the user is still unhappy? If so, the criteria are wrong.

Ask in rounds. Number each question, give your recommended answer, and word it so "yes" accepts the recommendation.

    ❓ **Q1** - **<title>**: <question>

    ➡️ <recommended answer>

Finding facts is your job. Look up anything the environment can answer. Ask the user only for decisions, preferences, and knowledge that exists only in their head.

The session is done when every field is stated or confirmed and the user agrees with the statement. End with the final goal statement.
